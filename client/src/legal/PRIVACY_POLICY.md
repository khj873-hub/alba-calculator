# 퍼펙트 근태관리 개인정보처리방침

- **시행일**: 2026-05-01
- **버전**: v1.0

주식회사 지누소프트(이하 "회사")는 정보주체의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수하기 위해 본 개인정보처리방침을 수립·공개합니다.

---

## 1. 수집하는 개인정보 항목

### 1.1 사장님(회원) 정보
| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 필수 | 사업장명, 관리자 PIN(해시 저장), 사장님 이메일 | 신청 폼·운영자 등록 |
| 선택 | 사업장 GPS 좌표(위치 제한 설정 시) | 사장님 직접 등록 |
| OAuth 시 | 구글 계정 ID(sub), 이메일, 이름, 프로필 사진 URL | 구글 OAuth 인증 |

### 1.2 직원 정보
| 항목 | 비고 |
|---|---|
| 이름 | 사장님이 직접 입력 |
| 시급(원) | 급여 계산용 |
| 색상(표시용) | UI 구분용 |
| 직원별 고유 출근 링크 토큰 | 자동 발급 |
| 출퇴근 일시 | 직원/사장님 입력 |
| 휴가 사용 기록(연차·반차·병가·경조사·날짜·메모) | 사장님 입력 |
| GPS 위치(출퇴근 시, 사업장 위치 제한 사용 시) | 브라우저 위치 API |

> ⚠️ **직원 정보는 사장님(회원)의 위탁을 받아 회사가 처리**합니다. 사장님은 직원으로부터 정보 수집·이용·서비스 사용 동의를 별도로 받아야 합니다.

### 1.3 자동 수집 정보
- 서비스 이용 시 발생하는 접속 기록(IP·시간), 브라우저 정보, 세션 토큰
- 쿠키 및 sessionStorage(세션 유지용)

## 7. 안전성 확보 조치

- 관리자 PIN은 단방향 해시(scrypt)로 저장합니다. 원본 PIN은 저장하지 않습니다.
- 구글 OAuth ID Token은 검증 후 즉시 폐기되며, 액세스/리프레시 토큰은 보관하지 않습니다.
- 모든 통신은 HTTPS(TLS)로 암호화됩니다.
- 세션 토큰은 24시간 만료되며, sessionStorage에 저장되어 브라우저 종료 시 자동 폐기됩니다.
- 사업장별 데이터는 논리적으로 분리되어 다른 사업장에서 접근할 수 없습니다.
- 운영자 콘솔은 사전 등록된 이메일(ADMIN_EMAILS)로만 접근 가능합니다.

## 8. 자동 수집 정보·쿠키 사용

- 본 서비스는 세션 유지를 위해 브라우저 sessionStorage를 사용합니다 (서드파티 추적 쿠키 미사용).
- 자동 수집 항목: 세션 토큰, OAuth 콜백 임시 state.
- 정보주체는 브라우저 설정을 통해 저장소 사용을 거부할 수 있으나, 그 경우 서비스 이용이 제한됩니다.

## 9. 위치정보 처리

본 서비스는 위치 기반 출근 체크 기능을 제공합니다.

| 항목 | 내용 |
|---|---|
| 수집 정보 | 직원의 출퇴근 시점 GPS 좌표(위도·경도) |
| 수집 방법 | 브라우저 Geolocation API (직원의 사전 동의 필요) |
| 이용 목적 | 사업장 등록 좌표와의 거리 비교 (반경 내 출근 검증) |
| 저장 여부 | **저장하지 않음** — 거리 계산 후 즉시 폐기. 기록되는 것은 출퇴근 시각뿐 |
| 위치 제한 미설정 시 | GPS 정보 수집 안 함 |

> ⚠️ 위치정보의 보호 및 이용 등에 관한 법률에 따라, 위치정보를 본격적으로 수집·저장·처리하는 경우 별도 신고가 필요할 수 있습니다. 현재 본 서비스는 GPS 좌표를 저장하지 않고 거리 계산용으로만 1회 사용 후 폐기합니다.
