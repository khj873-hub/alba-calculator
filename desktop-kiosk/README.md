# 퍼펙트근태 키오스크 — 얼굴 출근 체크 (P0 데모)

맥북용 데스크탑 키오스크 데모. 카메라로 얼굴을 등록하고, 얼굴 인식으로 출근/퇴근을 체크한다.
**P0 데모 목적**: 동작·정확도·속도 체감. (서버 연동·암호화·법적 동의 흐름은 P1)

## 실행 (맥북)

```bash
cd desktop-kiosk
npm install        # 최초 1회 (Electron 다운로드)
npm start          # 앱 창이 열림 → 카메라 권한 허용
```

> 처음 실행 시 macOS가 **카메라 접근 권한**을 묻습니다 → 허용.
> 모델은 CDN에서 받으므로 **인터넷 연결**이 필요합니다(P0 한정. 추후 로컬 번들로 오프라인화).

## 사용법

1. **얼굴 등록** — 오른쪽 패널에 이름 입력 → 카메라 정면 → "현재 얼굴 등록"
2. **출근 체크** — 화면을 보면 실시간으로 이름이 뜸 → (대리출근 방지 ON이면) **눈 한 번 깜빡** → "출근 / 퇴근 체크" 버튼
3. 같은 사람이 같은 날 다시 누르면 **퇴근**으로 기록
4. 우하단 기록/등록 목록 확인, "데모 데이터 초기화"로 리셋

## 설치파일(.dmg) 만들기 (선택)

```bash
npm run dist:mac   # dist/ 에 .dmg 생성
```

> 배포(다른 맥에 설치)하려면 **Apple Developer 서명·공증**이 필요합니다(P2). 본인 맥에서 테스트만 하면 `npm start`로 충분합니다.

## 구조

```
desktop-kiosk/
├── main.js              # Electron 메인(창·카메라 권한)
├── package.json         # electron / electron-builder
└── renderer/
    ├── index.html       # 키오스크 화면
    ├── app.js           # 얼굴 등록·인식·라이브니스·기록 (face-api.js, 기기 내 처리)
    └── style.css
```

## P0 데모의 한계 (의도된 범위)

- 데이터는 **이 기기 localStorage**에만 저장(데모). 서버·DB 연동은 P1.
- 얼굴 **임베딩만** 저장하고 원본 사진은 저장 안 함(개인정보 최소화 원칙은 데모에도 적용).
- 라이브니스는 **눈 깜빡임 1동작**의 간이 버전. 정교한 위조 방지는 P1.
- 정확도 임계값(`MATCH_THRESHOLD=0.5`)·깜빡임 민감도는 `renderer/app.js` 상단에서 조정 가능.
