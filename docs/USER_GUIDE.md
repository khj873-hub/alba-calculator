## 1. 서비스 소개

### 핵심 기능
- ✅ **출퇴근 기록** — 직원이 직접 찍거나 사장이 대리 처리
- ✅ **급여 자동 계산** — 시급 × 근무시간 + 주휴수당 + 휴게시간 공제
- ✅ **GPS 위치 제한** — 사업장 반경 안에서만 출퇴근 가능
- ✅ **급여 명세서** — PDF/CSV 다운로드, 3.3% 공제 자동 반영
- ✅ **휴가 관리** — 연차·반차·무급·병가·경조사 4종 등록
- ✅ **야간 근무 정확 분할** — 자정 넘는 근무는 일자별로 시간 분리
- ✅ **두 가지 직원 사용 모드** — 매장 공용 키오스크 / 개인 링크

### 누구를 위한 서비스인가
- **소상공인·자영업** (카페·식당·매장)
- **중소 사업장 HR** (10명 이하 직원 관리)
- **연봉제 / 시급제 / 알바 혼합** 사업장 모두 가능

## 2. 사장님(관리자) 사용법

### 2.1 사업장 신청하기

본 서비스는 **사장님이 직접 사업장을 생성하지 않습니다**. 신청서 제출 → 운영자가 등록 → 사업장 URL과 관리자 PIN 전달 받는 흐름입니다.

1. **신청서 작성**: [퍼펙트 근태관리 신청 폼](https://docs.google.com/forms/d/e/1FAIpQLSfqabZynjYejxaNUbJoCAL1LmBFZh5a1lCF4WudjaNvFEtVkg/viewform)
   - 사업장 이름
   - 사장님 연락처
   - 직원 수·운영 방식
2. **운영자 등록**: 신청서 확인 후 영업일 기준 1~2일 내 등록
3. **전달받는 정보**
   - 사업장 URL (예: `https://alba-calculator-production.up.railway.app/abc123`)
   - 관리자 PIN (4자리 이상)
4. **URL을 즐겨찾기**에 추가하고, **PIN은 안전한 곳에 보관**하세요

### 2.2 관리자 로그인

1. 사업장 URL의 우측 상단 **🔒 (자물쇠 아이콘)** 또는 직접 `/{slug}/manager` 접속
2. PIN 입력 → 24시간 세션 유지
3. 세션 만료 시 페이지 새로고침 후 PIN 재입력

### 2.3 직원 추가

1. 관리자 대시보드 → **"+ 직원 추가"** 클릭
2. 입력
   - 이름
   - 시급 (원)
   - 색상 (구분용)
   - **급여 계산 적용** — OFF 시 근태만 기록, 급여 산정 제외 (수습/임원/연봉제 등)
3. **저장**
4. 등록 후 **🔗 출근 링크 복사**로 직원에게 카카오톡·문자 전달

### 2.4 직원 출근 모드 선택

대시보드 하단 **🏠 직원 홈 화면 모드** 섹션에서 선택:

| 모드 | 설명 | 추천 사업장 |
|---|---|---|
| **🖥 키오스크** | 매장 단말기에 사업장 URL 띄워두고 직원이 자기 카드 골라서 출퇴근 | 카페·매장 (공용 태블릿 1대) |
| **🔗 개인 링크** | 직원 각자 받은 링크로 본인 화면 접속, 본인만 출퇴근 가능 | 직원이 각자 휴대폰 사용 |

### 2.5 GPS 위치 제한 설정

대시보드 하단 **📍 출퇴근 위치 제한** 섹션:

1. **현재 위치로 설정** 클릭 (사업장 안에서 클릭)
2. 허용 반경 입력 (권장: 실외 100m, 실내 200~300m)
3. PIN 입력 → 저장

이후 직원은 사업장 반경 안에서만 출퇴근 가능. 관리자 PIN으로 로그인한 상태에선 위치 제한 우회.

### 2.6 직원 출퇴근 처리 (사장이 직접)

- 대시보드 직원 카드의 **🟢 출근 처리 / 🔴 퇴근 처리** 버튼
- 관리자 세션이 있으므로 GPS 안 잡혀도 가능

### 2.7 근태 기록 관리

하단 **📋 근태** 탭:
- **월 이동**: 좌우 화살표
- **직원 필터**: 셀렉트 박스
- **편집 ✏️**: 출근/퇴근 시간 직접 수정
- **삭제 🗑**: 클릭 → "삭제 확정" 빨간 버튼 → 다시 클릭하면 삭제

### 2.8 급여 계산 + 명세서 출력

하단 **💵 급여** 탭:
- **월 이동**: 좌우 화살표
- **사업자명 입력**: 명세서 헤더에 표시됨
- **휴게시간 1시간 공제** 토글 (전체 직원 적용)
- **직원별 주휴수당 ON/OFF** 토글
- **📄 급여 명세서 PDF 출력** — 새 창에서 인쇄 가능
- **📊 엑셀(CSV) 다운로드** — 엑셀에서 열기

## 3. 직원 사용법

### 3.1 처음 출근 링크 받았을 때

1. 사장님이 보내준 링크를 누름 (예: `.../abc123/e/xxxxxxx`)
2. **첫 출근 시 GPS 권한 허용** (위치 제한 사용 시 필수)
3. **🟢 출근하기** 버튼 클릭

### 3.2 출퇴근 찍기

- 출근: **🟢 출근하기** 클릭 → 위치 확인 → 완료
- 퇴근: **🔴 퇴근하기** 클릭

### 3.3 GPS 권한 거부했을 때

- 브라우저 주소창 좌측 **자물쇠/카메라 아이콘** 클릭 → 위치 권한 허용으로 변경
- 또는 모바일 설정 → 해당 브라우저 → 위치 접근 허용

### 3.4 내 근무 시간·예상 급여 확인

직원 페이지에서 자동으로 표시:
- 이번 달 **근무일**·**총 시간**·**예상 급여**
- 주휴수당 포함 금액
- 3.3% 공제 후 실수령액
- 사장이 등록한 **🏖 이번 달 휴가** 내역
- 최근 출퇴근 기록 10건

## 4. 급여 계산 자세히

### 4.1 기본급
```
기본급 = (총 근무시간 / 60) × 시급
```

### 4.2 휴게시간 공제 (선택)
**휴게시간 1시간 공제** 토글 ON → 하루 근무시간에서 60분 자동 차감 후 시급 계산
- 일 4시간 미만 근무는 차감 안 됨 (최대 0까지)

### 4.3 주휴수당 (직원별 ON/OFF + 사업장별 기준)
근로기준법 기준 자동 계산:
```
사업장 기준 시간 이상 근무 시 (기본 15시간)
주휴수당 = (주 근무시간 / 40) × 8 × 시급
```
- 직원 카드 우측 **"주휴수당 ON/OFF"** 버튼으로 **직원별** 적용
- 대시보드 **📅 주휴수당 정책** 섹션에서 **사업장 단위** 커스터마이즈 (휴가 정책 토글과 독립, 항상 노출)
  - **기준 시간**: 15(법정) / 20 / 30 시간 프리셋 또는 0~40 사이 직접 입력
  - **주차 시작 요일**: 월요일(표준) / 일요일 (영업 사이클이 일요일부터인 매장은 일요일 권장)
- 사업장 설정에서 **연차 사용일을 기준 시간 카운트에 포함**할지 별도 토글 (휴가 정책 ON일 때만)

### 4.4 주휴수당이 시급에 포함된 경우 (포괄임금) 🆕

알바 공고에서 흔히 보는 **"시급 13,000원 (주휴 포함)"** 형태로 운영되는 직원은 매주 별도 주휴수당이 지급되지 않습니다.

#### 직원 입장에서 확인하는 법
- 직원 개인 페이지의 **시급 표기**에 **"(주휴 포함)"** 라벨이 보이면 포함 모드
- 예상 급여 박스에 **"주휴수당 시급 포함 (별도 지급 없음)"** 안내가 표시됨
- 명세서·CSV 시급 줄에 분해 표기가 보임 (예: `시급 13,000원 (주휴 포함 — 근로분 10,833원 + 주휴분 2,167원/시간)`)

#### 사장님 입장에서 설정
직원 추가/수정 페이지 → 시급 입력 카드 아래 **"주휴수당을 시급에 포함"** 토글 ON
- 환산 보조 표시 (포함 시급 ÷ 1.2 = 별도 시급 환산)
- 환산 시급이 2026 최저(10,320원) 미달이면 빨간 경고 — 포함 시급은 최소 **12,384원** 이상 권장
- 자세한 운영 가이드: **MANAGER_GUIDE 4.4 참고**

> 📌 포괄임금제는 **근로계약서에 "시급 ××원 (주휴수당 포함)" 명시**가 적법 운영의 전제입니다.

### 4.5 3.3% 공제 (사업소득세)
명세서에 자동 반영. 실수령액 = 총 지급액 × 96.7%

### 4.6 야간 근무 자정 분할 ⭐ (신규)
예: 5월 26일 22:00 ~ 5월 27일 06:00 (8시간 근무)
- **이전**: 5/26에 8시간 1일로 묶음
- **현재**: 5/26 2시간 + 5/27 6시간 → **2일 근무**로 정확히 분리
- 명세서 PDF/CSV에도 두 줄로 표시
- 근태 탭에선 🌙 야간/익일 라벨로 표시

## 5. 휴가 관리

### 5.1 휴가 정책 설정 (대시보드)

대시보드 하단 **🏖 휴가 정책** 섹션 열기:

| 토글 | 설명 |
|---|---|
| **휴가를 급여에 반영** | OFF여도 휴가 등록·표시는 항상 가능. 급여 자동 계산에만 반영 안 됨 |
| **유급 연차 1일 환산** | `시급 × 8시간` 또는 `평일 평균 근무시간 × 시급` |
| **연차 사용일을 주휴수당 기준 시간 카운트에 포함** | ON 시 근로기준법 기본. 연차 사용일도 일한 것으로 간주 (기준 시간은 **📅 주휴수당 정책** 섹션에서 사업장별 설정 — 기본 15시간) |

> 📅 **주휴수당 정책 섹션** (대시보드, 휴가 정책 토글과 독립): 기준 시간(15/20/30/직접 입력 0~40) + 주차 시작 요일(월/일) 변경 가능. 변경 즉시 모든 직원의 급여·명세서·CSV에 일관 반영.

💡 **연봉제·5인 미만 사업장 권장**: "휴가를 급여에 반영" **OFF**. 휴가 기록만 남기고 급여 계산은 별도 처리.

### 5.2 휴가 등록 (근태 탭)

근태 탭 상단의 **🏖 휴가** 버튼:

1. 직원 선택
2. 날짜 선택
3. 유형 선택
   - **연차** (유급): 환산 모드에 따라 자동 계산
   - **무급**: 급여 0
   - **병가**: 급여 0 (정산은 사업장 자율)
   - **경조사**: 급여 0
4. 단위 선택
   - **하루** (1일)
   - **오전 반차** (0.5일, 09:00 전후)
   - **오후 반차** (0.5일, 13:00 전후)
5. 메모 (선택)
6. **저장**

같은 날 오전 반차 + 오후 반차를 다른 유형으로 등록 가능 (예: 오전 연차 + 오후 병가).

### 5.3 휴가 삭제

근태 탭의 휴가 카드 우측 **🗑** 버튼:
1. 1번 클릭 → 빨간 **"삭제 확정"** 버튼으로 변화
2. 다시 클릭 → 즉시 삭제

### 5.4 휴가가 급여에 반영되는 방식 (마스터 ON 상태)

- **유급 연차** → `paid_leave_pay` 항목으로 급여에 합산
- **연차 + 근무 합산** → 사업장 기준 시간(기본 15시간) 판단 시 함께 카운트 (설정 ON 시)
- **무급/병가/경조사** → 일수만 카운트, 급여 0

## 6. 자주 묻는 질문

### Q. PIN을 잊어버렸어요
A. 운영자에게 문의해주세요 (개발자 이메일 또는 신청 폼에 동일하게 작성). PIN 초기화 후 새 PIN을 안전한 방법으로 전달드립니다.

### Q. 직원 한 명만 급여 계산에서 빼고 싶어요 (수습/임원/연봉제)
A. 직원 추가/수정 시 **"급여 계산 적용"** 토글 OFF. 근태는 그대로 기록되고 급여만 0원 처리.

### Q. 야간 근무가 1일·합계로 잡혀요
A. 2026-05-26 업데이트로 **자정 기준 자동 분할**됩니다. 예: 22시~6시 근무 → 2일·각각 2시간/6시간으로 분리. PDF/CSV도 자동 반영.

### Q. 휴가 등록 버튼이 안 보여요
A. 2026-05-26 업데이트 후엔 사업장 설정 상관없이 **항상 노출**됩니다. 보이지 않으면 페이지 새로고침.

### Q. 직원이 사업장 밖에서 출퇴근 찍으면 어떻게 되나요
A. **GPS 위치 제한 설정 시** 차단됩니다 ("사업장 반경 N미터 밖" 메시지). 미설정 시 어디서나 가능.

### Q. 키오스크 모드와 개인 링크 모드를 둘 다 쓸 수 있나요?
A. 사업장당 한 가지만 선택. 대시보드에서 언제든 전환 가능.

### Q. 명세서를 직원에게 어떻게 전달하나요
A. **📄 PDF 출력** 후 인쇄·PDF 저장·카카오톡 전송. 또는 **📊 CSV 다운로드** 후 메일 첨부.

### Q. 잘못 등록한 직원/근태/휴가를 삭제하면 데이터가 영구히 사라지나요?
A. 네, 복구 불가. **🗑** 클릭 후 **"삭제 확정"** 버튼이 한 번 더 나오는 이유.

### Q. 휴가 정책 OFF로 토글하면 이미 등록한 휴가가 사라지나요?
A. **데이터는 보존됩니다**. 화면 표시·급여 계산만 일시 제외. 다시 ON 켜면 즉시 복원.

### Q. 한 명이 같은 날 두 번 출근/퇴근을 찍을 수 있나요?
A. 네. 점심 빼고 오전·오후 따로 일하는 패턴 가능. 급여는 합산.

### Q. 시급에 주휴수당이 이미 포함된 직원은 어떻게 관리하나요?
A. 직원 추가/수정에서 **"주휴수당을 시급에 포함" 토글 ON**. 이후 매주 별도 주휴수당 자동 산정 없이 시급만으로 계산되고, 명세서에는 시급이 `13,000원 (주휴 포함 — 근로분 10,833원 + 주휴분 2,167원/시간)` 형태로 분해 표기됩니다. 직원 본인 페이지에도 **"주휴수당 시급 포함 (별도 지급 없음)"** 안내가 자동 노출됩니다. 자세한 내용은 **4.4 참고**.

## 7. 주의사항

### 7.1 데이터 보관·자동 백업
- 모든 데이터는 서버 DB(SQLite, `alba.db`)에 저장됩니다
- **자동 백업**: Cloudflare R2로 **실시간 복제** (Litestream 사이드카, 변경분 10초 간격 스트리밍 + 24시간마다 스냅샷, 30일 보관)
- 컨테이너 재시작/배포 시 R2에서 자동 복원 → **데이터 손실 위험 없음**
- 복원 절차·운영자 매뉴얼: [docs/BACKUP.md](BACKUP.md)
- **사업장 삭제 시 모든 직원·근태·휴가 데이터 즉시 삭제** — 백업본도 30일 후 자동 폐기, 신중히

### 7.2 PIN 관리
- 4자리 이상, 직원·외부에 노출되지 않게
- 사업장 위치 변경, 사업장명 변경, 휴가 정책 변경 모두 PIN 필요
- PIN 변경: 대시보드의 직원 추가 옆 메뉴에서

### 7.3 직원 출근 링크
- 각 직원에게 발급되는 고유 링크
- 링크를 알면 해당 직원 페이지 접근 가능
- **유출 시 🔄 재발급** 버튼으로 기존 링크 무효화 가능

### 7.4 시간 표시
- 모든 시간은 **한국 시간(KST)** 기준
- 명세서·CSV도 KST 시각

### 7.5 5인 미만 사업장 (근로기준법)
- 연차 유급휴가·연장/야간/휴일수당 **법적 의무 없음**
- 단, 근로계약서에 명시했다면 그대로 적용
- 본 서비스는 이 분기를 직접 자동 판정하지 않으니, 사장님이 정책 결정 후 토글 사용

### 7.6 신규 기능 안내
- 새 기능이 추가되면 **페이지 새로고침**으로 최신 화면 받음
- 캐시 문제 시 강제 새로고침 (Mac: `Cmd+Shift+R`, Windows: `Ctrl+F5`)
