# 얼굴 인식 출근 체크 (데스크탑 키오스크 앱) 기획안 v1

- **작성일**: 2026-06-12
- **상태**: 🟡 초안 — 검토/확정 대기
- **트리거 문구**: "카메라 기반으로 얼굴 인식해서 출근 체크 / 맥북·윈도우 설치 프로그램 형태"
- **결정된 방향**: 배포 형태 = **Electron 데스크탑 설치앱(.dmg/.exe)** · 진행 = **기획(PRD) 먼저**

---

## 1. 목적

현재 출근 인증은 **GPS 위치 기반**(현장 반경 안에서만 출근 가능). 그러나:
- 직원이 **휴대폰 없이** 출근하거나 위치 권한을 끄면 체크 불가
- **대리 출근(버디펀칭)** — 동료가 대신 위치 안에서 찍어줄 수 있음
- 매장 고정 단말에서 **누가 찍었는지 본인 확인**이 안 됨

→ **현장 고정 단말(맥/윈도우)에서 얼굴로 본인을 확인**해 출근/퇴근을 기록한다.
GPS를 **대체**가 아니라 **현장 키오스크 인증 수단**으로 추가하는 것이 1차 목표.

## 1.5 운영 구조 — 기존 웹 무변경 + 데스크탑 공존 (확정)

**핵심 원칙: 백엔드(서버·DB)는 하나, 클라이언트만 둘로 배포한다.**

```
                [ 기존 Node 서버 + DB ]  ← 하나만 운영 (Railway)
                 직원·출퇴근·급여·얼굴임베딩 전부 여기
                  ▲                         ▲
            HTTPS │                         │ HTTPS
   ┌──────────────────┐        ┌──────────────────────────┐
   │  웹 (브라우저)      │        │  데스크탑 설치앱(Electron)    │
   │  지금 그대로 운영    │        │  같은 화면 + 얼굴인식 키오스크   │
   └──────────────────┘        └──────────────────────────┘
```

- **기존 웹은 코드·운영 무변경** — 사장·직원은 지금처럼 브라우저 사용
- **데스크탑 앱은 "추가 클라이언트"** — 같은 서버·DB에 연결되어 **데이터 통합**(웹에서 등록한 직원이 키오스크에서 인식되고, 출근 기록도 한곳에 모임)
- **클라이언트 코드 공유, 빌드만 분리**: 웹 → Railway 배포(현행) / 데스크탑 → 같은 코드 + Electron 껍데기 → `electron-builder`로 `.dmg`·`.exe`
- 사업장은 상황에 맞게 **웹만 / 데스크탑만 / 둘 다** 선택 (예: 입구엔 키오스크 설치앱, 사장은 웹)
- **얼굴 인식은 데스크탑(키오스크) 전용**으로 두고 웹은 기존 기능만 유지(브라우저도 기술적으론 가능하나 범위 분리)
- **1차 대상 OS: macOS(맥북)** — `.dmg` 우선, 윈도우 `.exe`는 이후

## 4. 사용자 시나리오

### A. 직원 얼굴 등록 (최초 1회)
1. 관리자/직원이 키오스크에서 "얼굴 등록" → 직원 선택(또는 토큰 링크)
2. **동의 화면** — 생체정보 수집·이용·보관기간 안내 → 동의 체크
3. 카메라 안내선에 얼굴 맞춤 → 2~3컷 캡처 → **임베딩 생성**(기기 내) → 서버에 암호화 저장
4. 완료. 원본 사진은 저장하지 않음

### B. 출근/퇴근 체크 (매일)
1. 직원이 키오스크 앞에 섬 → 얼굴 자동 감지
2. **라이브니스** 안내("천천히 눈을 깜빡여 주세요") → 통과
3. 임베딩 대조 → 본인 확정 → "○○○님 출근! 09:01" 표시 + 기록 저장
4. 같은 사람이 다시 오면 상황에 따라 **퇴근**으로 기록(기존 출퇴근 토글 로직 재사용)
5. 실패(미등록·불일치·라이브니스 실패) → 재시도 / 3회 시 PIN·직원선택 폴백

### C. 관리자 운영
- 등록된 얼굴 목록 조회 / **삭제(재등록)** / 직원별 임베딩 관리
- 인증 방식(얼굴/GPS/둘 다) 사업장 설정
- 출근 기록은 기존 근태/급여 탭에 그대로 반영

## 5. 화면 목록

| 화면 | 역할 |
|---|---|
| 키오스크 메인(대기) | 카메라 미리보기 + "출근하려면 화면을 봐주세요" |
| 얼굴 등록 | 동의 → 캡처 → 완료 |
| 인식 결과 | "○○○님 출근/퇴근" 또는 실패 안내 |

| 관리자 — 얼굴 관리 | 등록 목록·삭제·재등록, 인증 방식 설정 |

## 6. 기술 구조 (안)

```
[Electron 데스크탑 앱 (맥/윈도우)]
  └ 렌더러: 기존 React 클라이언트 재사용 + 키오스크 화면 추가
       └ 카메라: getUserMedia
       └ 얼굴 인식: face-api.js (TensorFlow.js, 기기 내) — 감지·정렬·임베딩(128~512d)
       └ 라이브니스: 눈 깜빡임/머리 움직임 간이 검출
  └ 메인 프로세스: 카메라 권한·전체화면·자동시작·업데이트
       │
       ▼ HTTPS
[기존 Node 서버 (Railway)]
  └ /api/face/enroll   : 임베딩 등록(암호화 저장)
  └ /api/face/verify   : 임베딩 매칭(또는 클라에서 매칭 후 출근만 전송)
  └ /api/attendance/*  : 기존 출퇴근 기록 재사용
  └ DB: face_templates(employee_id, embedding(enc), created_at) — 원본 이미지 없음
```

- **매칭 위치 선택지**:
  - (a) **클라이언트 매칭** — 서버가 임베딩 목록 내려주고 기기에서 대조(얼굴 데이터 서버 체류 최소, 단 임베딩이 단말로 내려감)
  - (b) **서버 매칭** — 단말이 임베딩만 보내 서버가 대조(단말엔 안 남음) ← **1차 제안**
- **패키징**: `electron-builder` → 맥 `.dmg`(공증/서명 [CONFIRM]) / 윈도우 `.exe`(NSIS)
- **오프라인**: 네트워크 끊겨도 임시 기록 후 복구 시 동기화([CONFIRM], MVP 제외 가능)

## 7. ⚠️ 비기능 요구 — 법적·보안 (필수)

> 얼굴 = **민감정보(생체인식정보)**. 개인정보보호법상 일반 개인정보보다 강하게 규제됨.

1. **별도 동의(법 제23조)** — 일반 약관 동의와 **분리된** 생체정보 수집·이용 동의 필수. 미동의 직원은 GPS/PIN 등 대체 수단 제공
2. **목적 제한·최소 수집** — 출근 본인확인 목적만. **원본 이미지 저장 금지, 임베딩만**
3. **암호화 저장** — 임베딩을 DB에 암호화(at-rest). 전송 HTTPS
4. **보관기간·파기** — 퇴직/해지 시 즉시 파기. 보관기간 명시 [CONFIRM]
5. **안전성 확보조치** — 접근권한 통제, 백업 시에도 암호화(기존 R2 백업 영향 검토)
6. **라이브니스** — 사진·영상 도용 방지(대리출근). 미구현 시 위조에 취약함을 운영자에 고지
7. **오인식 대응** — 실패 시 강제 통과 금지, 수동 본인확인 폴백

→ 상용 배포 전 **개인정보처리방침 개정 + 동의 문구 추가**가 선행되어야 함.

## 8. 제외 범위 (MVP 아님)

- 마스크 착용 인식 최적화, 다중 얼굴 동시 처리
- 표정/감정 분석, 연령 추정 등 부가 분석 (수집 목적 외 → 금지)
- 완전 오프라인 장기 운영, 단말 무인 자동 업데이트(추후)
- 모바일(폰) 얼굴 출근 — 본 건은 **고정 키오스크** 한정
