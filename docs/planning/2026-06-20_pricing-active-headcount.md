# 요금제 — 활성 인원 + 기능 차등 (기획)

> 작성일: 2026-06-20 · 상태: 기획 확정 대기(가격·인원수 TBD), 개발 미착수

## 1. 배경 / 문제
업체 규모별로 요금제를 차등하려 함. 단순 "등록 인원 제한"은 **알바 churn**(수시 교체) 때문에 누적 기준이면 금방 막힘. 동시에 퇴사자 기록은 **법적 보관 의무**(임금대장·근로계약 3년) 때문에 삭제 불가.

## 2. 확정된 방향
- **과금 기준: 활성(재직) 인원 + 기능 차등** (결정됨)
- **한도 초과 시: 신규 등록 차단 + 업그레이드 유도** (결정됨)

## 3. 핵심 설계 — 활성 인원 카운트
- 직원에 **재직/퇴사 상태**(`status: active | resigned`, 또는 `resigned_at`) 추가
- **과금 인원 = active 직원 수만** 카운트 (퇴사자 제외)
- **퇴사 처리 = soft**(삭제 아님) → 기록 전부 보존, 조회는 읽기전용, 활성 카운트에서 -1 → 자리 반환
- 효과: "활성 N명 한도"면 1년에 그 몇 배가 거쳐가도 동시 재직만 N명 이하면 계속 사용

## 4. 한도 초과 동작 (확정)
- 활성 수 == 플랜 한도 상태에서 신규 직원 등록 시 → **차단**
- 안내 모달: "현재 플랜(활성 N명)을 초과했습니다. 기존 직원을 퇴사 처리하거나 플랜을 업그레이드하세요." + 업그레이드 CTA
- 퇴사 처리 후 자리 나면 즉시 등록 가능

## 5. 플랜 구성 (✅확정 2026-06-20, plans.ts 구현됨)
| 플랜(key) | 활성 인원 | 출퇴근 알림 | 가격/월 |
|---|---|---|---|
| 무료(free) | 3명 | ❌ | 0원 |
| 베이직(basic) | 5명 | ✅ | 9,900원 |
| 프로(pro) | 20명 | ✅ | 29,900원 |
| 엔터프라이즈(enterprise) | 무제한 | ✅ | 별도 문의 |
| (레거시 paid) | 무제한 | ✅ | 신규부여 금지, 기존 호환 |

- 한도·단가는 `server/src/plans.ts` + 클라 `PLANS_DISPLAY`(api/index.ts) **두 곳 동기화**.
- GPS·PDF·다매장 게이트는 미구현(현재는 알림만 유료 게이트). 결제 플로우 미구현 — 카카오 채널 문의 CTA + 운영자 콘솔 수동 부여.

## 6. 미결 정책 (확정 필요)
- [ ] 무료 플랜 활성 인원 수 (전환 깔때기 폭)
- [ ] 각 플랜 가격 (경쟁사·시장 단가 조사 후)
- [ ] 퇴사자 기록 보관 기간 (법적 최소 3년 vs 영구)
- [ ] 재입사 처리: 신규 추가 vs 기존 복원
- [ ] 기존 사업장 grandfathering (이미 활성 직원이 한도 초과인 곳은 유예)

## 7. 구현 단위 (진행 상황)
- **P1 ✅완료**: `employees.status`/`resigned_at` 마이그레이션 + 퇴사/복원 UI + 활성 카운트 표시
- **P2 ✅완료**: `plans.ts`(plan→활성한도) + 등록·복원 시 한도 체크(403 PLAN_LIMIT) + 업그레이드 모달(EmployeeFormPage) + 대시보드 "활성 N/M명" 표시
  - **free 한도 = 3명**(server/src/plans.ts + client PLAN_ACTIVE_LIMIT). 변경 시 두 곳 동기화.
  - 업그레이드 CTA는 카카오 채널 문의로 연결(자체 결제 플로우 없음 → 추후).
- **P3 (진행 중)**: 기능 게이트(플랜 연동) + 업그레이드 유도 UI
  - ✅ **출퇴근 알림(SMS·카카오톡) 유료 전용** — plans.ts features.notifications. 2중 잠금: 무료는 켜기 403(PLAN_FEATURE, manager+admin) + 발송 시점 게이트(무료면 미발송, 비용 방지). 무료 UI는 🔒 잠금 카드 + 업그레이드 CTA.
    - ⚠️ grandfathering: 무료인데 sms_enabled=1이던 기존 사업장은 배포 후 **발송 중단**(send 게이트). 플래그는 남아도 무해(게이트가 막음).
  - ✅ **GPS 위치 제한 유료 전용** — plans.ts features.gps. businesses location PATCH에서 무료가 lat/lng 설정 시 403 PLAN_FEATURE(해제=null은 허용). ManagerDashboard 위치 섹션 🔒 잠금.
  - ✅ **급여명세서 PDF·CSV 출력 유료 전용** — plans.ts features.payslipExport. ManagerPayrollPage 출력 버튼을 무료면 🔒 안내로 대체(클라 출력이라 UI 게이트). 급여 계산·조회 자체는 무료 유지.
  - ⚠️ **다매장 게이트 보류** — plan이 사업장 단위라 "한 사장님(user) 여러 매장"과 안 맞음(user 단위 플랜 모델 필요). 게다가 다매장 관리 기능 자체가 미구현. 별도 설계 필요.
- **P4 (예정)**: 운영자 콘솔 플랜·한도 관리 확장 (기존 plan free/paid 토글 확장)
  - 다단계 플랜(베이직/프로)은 현재 free/paid 2단계 → 확장 시 plans.ts + businesses.plan 값 추가

## 8. 기존 코드 연계 메모
- `businesses.plan`(free/paid) 이미 있음 → 다단계 플랜으로 확장
- `businesses.is_active`(정지) 와는 별개 개념
- 운영자 콘솔(AdminPage)에 plan 셀렉트 이미 있음 → 한도 표시·관리 추가
- 직원 테이블 현재 active 개념 없음 → status 컬럼 신규
