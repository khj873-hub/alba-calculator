## 1. 근로기준법 기준 정리 (사장님 입력 자료)

### 연차 발생 (제60조)
| 구분 | 조건 | 일수 |
|---|---|---|
| 1년 미만 | 월 개근 | **월 1일** (최대 11일) |
| 1년 이상 | 출근율 80%+ | **15일** |
| 3년 이상 | 2년 초과 매 2년 | **+1일 가산** |
| 21년+ | 상한 | **25일** |

### 근속연수별 누적
| 근속 | 일수 |  | 근속 | 일수 |
|---|---|---|---|---|
| 1년 | 15 | | 7년 | 18 |
| 3년 | 16 | | 9년 | 19 |
| 5년 | 17 | | 10년 | 20 |

### 연봉제 처리
- 연봉제든 시급제든 **근기법 동일 적용**
- 연봉에 연차수당 포함 → 계약서 명시 필요 (불명확 시 별도 지급 의무)
- 연봉에 미포함 → 미사용 연차 수당 별도 지급
- **연차수당 = 미사용 일수 × 1일 통상임금**
- 소멸시효: **3년**
- 퇴직 시 미사용 연차 → **14일 이내 정산 지급** (위반 시 3천만 원 이하 벌금)

### 사용 촉진 제도
- 사용자가 서면 통보로 적법 촉진 → **수당 지급 의무 소멸**
- 촉진 없이 미사용 → 다음 연도 초 수당 일괄 지급 원칙
- 노사 합의 시 이월 가능

### 5인 미만 사업장 (적용 제외)
| 항목 | 5인+ | 5인 미만 |
|---|:---:|:---:|
| 연차 유급휴가 | 의무 | **제외** |
| 연차수당 | 의무 | **제외** |
| 연장·야간·휴일수당 | 의무 | **제외** |
| 주휴수당 | 의무 | 의무 |
| 근로계약서 | 의무 | 의무 |
| 최저임금 | 의무 | 의무 |
| 휴게시간 | 의무 | 의무 |
| 퇴직금 | 의무 | 의무 |

- **단**: 계약서·내규에 연차 명시했으면 그대로 적용
- 상시근로자 산정: 1년 중 한 달이라도 5인 미만이면 의무 없음
