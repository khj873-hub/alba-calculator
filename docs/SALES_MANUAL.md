# 퍼펙트 근태관리 — 영업점 매뉴얼

> 영업 담당자가 사업주(사장님)에게 안내·세일즈할 때 쓰는 종합 자료.
> 최종 업데이트: 2026-06-20 · 서비스 URL: https://alba-calculator-production.up.railway.app

---

## 1. 한 줄 소개
> **직원 출퇴근부터 급여·주휴수당 자동 계산까지, 스마트폰 하나로 끝나는 근태 관리 서비스.**

단기 알바·장기 직원 모두를 한 곳에서. 무료로 시작하고 필요할 때 업그레이드.

## 2. 이런 사장님께 추천
- 직원 시급·근무시간 매달 엑셀로 정리하다 실수하는 분
- 알바 출퇴근을 카톡·전화로 확인하기 번거로운 분
- 매장을 자주 비우거나 여러 매장을 운영하는 분
- 주휴수당·야간수당 계산이 헷갈리는 분
- 업종: **카페·식당·편의점·미용실·학원** 등 시급 직원이 있는 모든 매장

---

## 3. 요금제 (핵심)
| 플랜 | 활성 직원 | 월 요금 | 주요 기능 |
|---|---|---|---|
| **무료** | 3명 | 0원 | 출퇴근 기록, 급여·주휴수당 자동 계산 |
| **베이직** ⭐인기 | 5명 | 9,900원 | 무료 + **출퇴근 알림(SMS·카카오)·GPS 위치제한·급여명세서 출력** |
| **프로** | 20명 | 29,900원 | 베이직 + 직원 20명까지 |
| **엔터프라이즈** | 무제한 | 별도 문의 | 프로 + 직원 수 제한 없음 (다점포·대형) |

**과금 기준 = 활성(재직) 직원 수.** 퇴사 처리하면 자리가 반환돼서, 알바가 자주 바뀌어도 동시에 재직 중인 인원만 한도 안이면 OK. (퇴사자 기록은 보존)

## 4. 무료 vs 유료 — 무엇이 잠기나
| 기능 | 무료 | 유료 |
|---|---|---|
| 출퇴근 기록 · 급여·주휴수당 계산 | ✅ | ✅ |
| 출퇴근 알림 (SMS·카카오) | 🔒 | ✅ |
| GPS 위치 제한 | 🔒 | ✅ |
| 급여명세서 PDF·CSV 출력 | 🔒 | ✅ |
| 활성 직원 | 3명 | 5~무제한 |

## 5. 가입·온보딩 흐름

### 무료 가입 (사장님이 직접)
1. https://alba-calculator-production.up.railway.app/create 접속 (또는 메인 "무료로 사업장 만들기")
2. **"새 사업자 등록하기"** → **구글 로그인**(본인 확인)
3. 사업장명 + 관리자 PIN 입력 → 완료, 바로 사용
- 구글 로그인 필수: PIN 분실해도 구글로 복구되고, 본인 확인이 됩니다. PIN은 매장 단말·일상 로그인용으로 병행.

### 유료 전환 (문의 → 운영자 설정)
1. 사장님이 **요금제 카드 "OO 문의하기"** 또는 도입 문의 폼 작성 (관심 플랜 선택)
2. 문의가 **운영자 콘솔**에 접수됨 (관심 플랜 표시)
3. **운영자가 해당 사업장 플랜을 베이직/프로/엔터프라이즈로 변경** → 즉시 기능 해제
4. 결제는 별도 수금 (현재 자동결제 미지원, 운영자 수동 처리)

> 영업점이 대신 등록도 가능: 사장님 정보 받아 운영자가 콘솔에서 사업장 생성·플랜 부여.

## 6. 주요 기능 (세일즈 포인트)
- **원터치 출퇴근** — 직원이 스마트폰으로 출퇴근 체크, 관리자 실시간 확인
- **급여·주휴수당 자동 계산** — 시급 × 근무시간, 주휴수당·야간(자정 분할)까지 자동
- **출퇴근 알림** (유료) — 직원이 찍으면 사장님 폰으로 SMS·카카오 알림. 매장에 없어도 실시간 파악
- **GPS 위치 제한** (유료) — 매장 반경 안에서만 출근 가능
- **급여명세서 출력** (유료) — 월별 PDF·CSV로 직원에게 전달
- **휴가 관리** — 연차·반차·병가·경조사 4종, 급여 반영 옵션
- **출퇴근 QR** — 매장 부착용 QR 포스터, 직원이 스캔해 바로 출퇴근
- **구글 로그인** — 안전 접근, PIN 분실 걱정 없음

## 7. 출퇴근 알림 비용 (유료 기능)
- 종류: SMS(단문), **건당 약 20원**
- 발송: 직원 1명당 출근 1건 + 퇴근 1건 = 하루 2건
- 예시(30일): 직원 5명 ≈ 월 6,000원, 10명 ≈ 12,000원
- 절감: 출근만 받기(절반), 추후 카카오 알림톡(더 저렴) 전환 예정

## 8. 자주 묻는 질문 (영업 응대용)
**Q. 무료로 어디까지 되나요?**
A. 직원 3명까지 출퇴근·급여 계산 전부 됩니다. 알림·GPS·명세서 출력은 유료예요.

**Q. 알바가 자주 바뀌는데 인원 제한 괜찮나요?**
A. 네. **재직 중인 인원**만 셉니다. 그만둔 직원은 퇴사 처리하면 자리가 비고 기록은 남아요.

**Q. 직원도 문자를 받나요?**
A. 아니요. 출퇴근 알림은 **사장님(등록 번호)만** 받습니다.

**Q. 가입에 구글 계정이 꼭 필요한가요?**
A. 무료 셀프가입은 구글 본인 확인이 필요해요. 어려우면 운영자가 대신 등록해드립니다.

**Q. 유료는 어떻게 결제하나요?**
A. 지금은 문의 주시면 운영자가 플랜을 적용하고 결제는 별도 안내드립니다. (자동결제는 준비 중)

**Q. PIN을 잊어버렸어요.**
A. 구글로 로그인하거나, 운영자에게 PIN 재발급을 요청하면 됩니다.
