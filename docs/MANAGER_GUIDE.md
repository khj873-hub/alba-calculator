## 1. 시작하기 — 사업장 등록

### 방법 A. 직접 등록 (가장 빠름, 5분)

1. 메인 페이지 https://alba-calculator-production.up.railway.app 접속
2. **"새 사업장 등록"** 또는 `/create` 직접 입력
3. 입력 항목
   - **사업장명** (예: "홍길동 편의점") — 변경 가능
   - **관리자 PIN** (4~8자리 숫자) — 분실 시 운영자 문의 필요하니 안전한 곳에 보관
   - **PIN 확인**
4. **등록하기** 클릭 → 사업장 코드(slug) 자동 발급, 관리자 대시보드로 바로 이동

### 방법 B. 신청 폼 (자세한 안내가 필요할 때)

1. [퍼펙트 근태관리 신청 폼](https://docs.google.com/forms/d/e/1FAIpQLSfqabZynjYejxaNUbJoCAL1LmBFZh5a1lCF4WudjaNvFEtVkg/viewform) 작성
2. 영업일 기준 1~2일 내 운영자가 사업장 등록 + URL·PIN 전달
3. 추가로 **구글 계정 연동** 가능 (이 경우 PIN 없이도 구글 로그인 가능)

### 발급받는 정보

```
사업장 URL: https://alba-calculator-production.up.railway.app/{내사업장코드}
관리자 PIN: 4~8자리 숫자
(선택) 연결된 구글 계정: my-business@gmail.com
```

> 💡 **URL을 즐겨찾기에 추가**하고 카카오톡 ‘나에게 보내기’로도 저장해두세요.

## 2. 관리자 로그인

세 가지 진입 방법 — 어느 방법이든 24시간 동안 로그인 상태 유지.

### 2.1 PIN 로그인

1. 사업장 URL 접속 → 우측 상단 **🔒 자물쇠 아이콘** 또는 `/{slug}/manager` 직접 입력
2. PIN 입력 → 관리자 대시보드 이동

### 2.2 구글 로그인 (선택 기능)

운영자가 사장님 구글 계정을 사업장에 연결해둔 경우:
- 로그인 화면에 **🔵 구글로 로그인** 버튼 노출
- 클릭 → 본인 구글 계정 선택 → 자동 진입
- PIN 분실 시 안전한 백업 수단

> 구글 로그인이 안 보이면 운영자에게 "구글 계정 연결" 요청해주세요.

### 2.3 24시간 세션

- 한 번 로그인하면 24시간 자동 유지
- 세션 만료 시 페이지 새로고침 후 PIN/구글 재로그인
- **다른 사람과 기기 공유 시** 사용 후 반드시 로그아웃

### 2.4 로그아웃

대시보드 상단 우측 **로그아웃** 버튼

## 4. 직원 추가·관리

### 4.1 직원 추가

대시보드 **+ 직원 추가** 버튼 → 입력 화면:

| 항목 | 설명 |
|---|---|
| **이름** | 카드와 명세서에 표시되는 이름 |
| **시급(원)** | 분당 자동 환산 — `(분 / 60) × 시급` |
| **색상** | 직원 카드 좌측 띠 색, 시각적 구분용 |
| **급여 계산 적용** | OFF 시 근태만 기록, 급여 0원 처리 (수습/임원/연봉제) |

저장 → 대시보드에 카드 추가됨 → **🔗 출근 링크 복사** 버튼으로 카카오톡·문자로 직원에게 전달.

### 4.2 직원 정보 수정

직원 카드 우측 **수정** 아이콘 → 이름·시급·색상·급여 적용 모두 변경 가능.

> 시급을 바꿔도 **과거 명세서는 그대로** 계산됩니다 (당시 시급 보존). 변경 시점 이후 근태부터 새 시급 적용.

### 4.3 주휴수당 직원별 ON/OFF

각 직원 카드의 **주휴수당** 토글:
- **ON**: 사업장 기준 시간(기본 15시간, **9.1에서 변경 가능**) 이상 근무 시 자동 산정
- **OFF**: 시급 × 근무시간만 계산

> 5인 미만 사업장이라도 주휴수당은 법정 의무입니다. 일부 직원만 OFF는 정책 결정 후 사용.
> 시급에 주휴수당을 미리 녹여 지급하는 포괄임금 운영은 **4.4 참고**.

### 4.4 주휴수당을 시급에 포함 (포괄임금 모드) 🆕

자영업에서 흔한 운영 방식 — **"시급 13,000원 (주휴수당 포함)"** 처럼 시급 단가에 주휴분을 미리 녹여 매주 별도 주휴수당 지급 없이 단순하게 운영합니다.

#### 언제 사용하나
- 매주 주휴수당을 따로 계산해 지급하는 게 번거로울 때
- 알바 공고에 "시급 ××원 (주휴 포함)"으로 모집한 직원에게 그 단가 그대로 적용할 때
- 근로계약서에 "시급 13,000원 (주휴수당 포함)" 형태로 명시한 경우

#### 설정 방법
직원 추가/수정 페이지 → 시급 입력 카드 아래 **"주휴수당을 시급에 포함"** 토글 ON

토글 ON 시 보조 표시
- **주휴 환산 별도 시급 ≈ ××원** (포함 시급 ÷ 1.2 · 주 40h 기준)
- **환산 시급이 2026 최저시급(10,320원) 미달**이면 빨간 경고 — 포함 시급은 최소 **12,384원** 이상 권장
- 근로계약서 명시 안내

#### 환산 공식 (주 40시간 기준)
```
포함 시급 = 별도 시급 × 1.2   (별도 → 포함)
별도 시급 = 포함 시급 ÷ 1.2   (포함 → 별도)

예) 별도 10,320 × 1.2 = 포함 12,384  → 끝수 올려 13,000원으로 운영하는 곳 多
    포함 13,000 ÷ 1.2 ≈ 별도 10,833  (주휴분 2,167원/시간)
```

#### 자동 변경되는 동작
| 위치 | 변화 |
|---|---|
| 직원 카드 (대시보드) | "(주휴 포함)" 라벨 노출 |
| 급여 페이지 직원 카드 | 주휴수당 ON/OFF 토글 **자동 숨김** + "주휴 포함 시급" 뱃지 |
| 급여 자동 계산 | `weekly_holiday_pay = 0` 강제 (이중 지급 방지) |
| PDF 명세서 / CSV 헤더 | `시급 13,000원 (주휴 포함 — 근로분 10,833원 + 주휴분 2,167원/시간)` 분해 표기 |
| PDF 명세서 지급 내역 | "기본급 (주휴 포함)" 한 줄 — 주휴수당 라인 자체가 사라짐 |
| 직원 개인 페이지 | "주휴수당 시급 포함 (별도 지급 없음)" 안내 박스 |

#### 법적 안전망
포괄임금제는 **근로계약서에 명시적 합의**가 있어야 적법합니다.
- 근로계약서에 `시급 13,000원 (주휴수당 ××원 포함)` 형태로 시급 구성을 명시
- 사장님이 일방적으로 시급에 녹였다고 주장하면 법적 효력 약함

#### 정책 충돌 시
| 다른 기능 | 포함 모드일 때 동작 |
|---|---|
| 직원 카드 주휴수당 ON/OFF 토글 | **자동 숨김** (시급에 이미 녹아있어 토글 의미 없음) |
| 사업장 📅 주휴수당 정책 (기준 시간, 주차 시작 요일) | **무관** — 포함 모드 직원에게 미적용 |
| 휴게시간 1시간 공제 | **독립적으로 그대로 적용** (휴게 공제는 근로시간 자체 조정이라 별개) |
| 유급 연차 환산 | 정상 적용 (포함 시급 그대로 사용) |

#### 모드 전환 시 주의
- 토글만 변경되고 **시급 수치는 그대로** 보존됩니다 (사장님이 의도해서 시급도 같이 조정)
- 별도 → 포함 전환: 시급 보존되어 "총 인건비가 줄어든 것처럼" 보일 수 있음. 의도한 거면 그대로, 아니면 시급 ×1.2로 수동 조정
- 포함 → 별도 전환: 마찬가지로 시급 ÷1.2 환산이 필요할 수 있음

### 4.5 출근 링크 발급·복사·재발급

- **🔗 출근 링크 복사** — 직원에게 보내는 고유 링크 (예: `/{slug}/e/xxxx`)
- **🔄 재발급** — 기존 링크 즉시 무효화 + 새 링크 생성. 직원 이탈/링크 유출 시 사용

### 4.6 직원 삭제 (주의)

- 직원 카드 **삭제** → 빨간 **삭제 확정** 버튼 한 번 더 클릭
- **삭제 시 해당 직원의 모든 근태·휴가 기록도 함께 삭제** — 복구 불가
- 대안: 삭제 대신 **급여 계산 적용 OFF**로 두면 기록은 보존하면서 비활성화

## 5. 직원 출근 방식 선택

대시보드 **🏠 직원 홈 화면 모드** 섹션:

| 모드 | 동작 | 추천 사업장 |
|---|---|---|
| **🖥 키오스크** | 사업장 URL을 매장 태블릿에 띄워두면 직원이 자기 카드 골라 출퇴근 | 카페·매장 (공용 단말기) |
| **🔗 개인 링크** | 각 직원이 본인 링크로만 접속, 본인 출퇴근만 가능 | 직원이 각자 휴대폰 사용 |

> 사업장당 한 가지만 선택. 언제든 전환 가능합니다.

### 키오스크 모드 운영 팁
- 매장 태블릿에서 사업장 URL 즐겨찾기 → "홈 화면에 추가"
- 인터넷 차단 환경에선 동작 안 됨 → 와이파이 확인

### 개인 링크 모드 운영 팁
- 각 직원에게 **🔗 출근 링크** 한 번만 보내면 됨
- 직원이 휴대폰 홈 화면에 추가하면 앱처럼 사용
- 링크 유출 의심 시 즉시 **🔄 재발급**

## 6. GPS 위치 제한

직원이 사업장 밖에서 출퇴근 찍는 걸 막는 기능. **선택 사항**.

### 설정 방법

1. 대시보드 **📍 출퇴근 위치 제한** 펼치기
2. **사업장 안에서** "현재 위치로 설정" 클릭 → GPS 권한 허용
3. **허용 반경** 입력
   - 권장: **실외 100m**, **실내(GPS 오차 고려) 200~300m**
4. **PIN 입력 → 저장**

### 동작
- 직원이 출근 버튼 클릭 → GPS 위치 확인 → 반경 안이면 ✅ / 밖이면 ❌ ("사업장 반경 N미터 밖")
- **관리자 세션**(PIN/구글 로그인 상태)에서는 위치 제한 우회 — 사장님이 대리 출근 처리 가능

### 해제
**범위 0** 또는 **위치 삭제** 옵션. 이후 어디서든 출퇴근 가능.

## 7. 출퇴근 처리

### 7.1 직원이 직접 (정상 운영)
- 키오스크/개인 링크 모드에서 직원이 본인 버튼 누름
- 위치 제한 시 GPS 통과 후 기록

### 7.2 사장이 대리 (직원이 못 찍었을 때)
- 대시보드 직원 카드의 **🟢 출근 / 🔴 퇴근** 버튼
- 관리자 세션이라 GPS 우회 가능
- 직원이 잊고 퇴근하지 않은 경우 사장이 대신 퇴근 처리

### 7.3 한 명이 같은 날 두 번
- 점심시간으로 끊고 오전·오후 따로 일하는 패턴 가능
- 출근 → 퇴근 → 다시 출근 → 퇴근 식으로 누적
- 명세서에는 두 줄로 표시되고 시간은 합산

### 8.2 직원 필터

### 8.3 기록 편집 ✏️

## 9. 주휴수당·휴가 정책과 휴가 등록

### 9.1 📅 주휴수당 정책 (사업장별 기준)

| **연차 사용일 처리** | 휴가 정책 ON일 때만 노출 — 9.2 참고 |

#### 동작
- 사업장이 주휴수당 지급 기준 시간을 직접 정의 — 법정 기준(15시간)보다 **엄격하게** 설정해 운영 가능 (예: 20시간 이상 근무자에게만 지급)
- 주차 시작 요일을 일요일로 두면, **일요일~토요일** 구간으로 주간 근무시간을 합산해서 기준 시간 충족 여부 판정

#### 권장 설정
- **단시간 알바 다수 사업장**: 15시간(법정 그대로)
- **풀타임 위주 사업장**: 20시간 또는 30시간 — 단시간 신입에게는 직원별 ON/OFF로 별도 정책
- **국내 표준 근무**: 주차 시작 = **월요일**

### 9.2 휴가 정책 설정 (1회 세팅)

- **연봉제·5인 미만**: 휴가 반영 **OFF** (휴가 기록만 남기고 정산은 별도)

## 10. 급여 계산 + 명세서 출력

대시보드 **💵 급여** 탭:

### 10.1 상단 설정

| 항목 | 설명 |
|---|---|
| **월 이동** | ◀ 5월 ▶ 화살표 |
| **사업자명 입력** | 명세서 헤더에 표시 |
| **휴게시간 1시간 공제** 토글 | 일 4시간 이상 근무에서 60분 자동 차감 |
| **직원별 주휴수당** | 직원 카드에서 ON/OFF, 여기선 확인만 |

### 10.2 계산식 요약

```
기본급 = (총 근무 분 / 60) × 시급
주휴수당 = (주 근무시간 / 40) × 8 × 시급         (사업장 기준 시간 이상, 기본 15시간 · 9.1에서 변경 가능)
유급 연차 = 시급 × 8시간 (또는 평균 근무시간)     (정책 ON 시)
총 지급액 = 기본급 + 주휴수당 + 유급 연차
3.3% 공제액 = 총 지급액 × 0.033
실수령액 = 총 지급액 × 0.967
```

### 10.3 출력

- **📄 PDF 명세서** — 새 창에서 인쇄/PDF 저장 → 카카오톡 전송
- **📊 CSV 다운로드** — 엑셀에서 열기, 일자별 근무·휴가 분리 표시
- **야간 자정 분할**도 자동으로 두 줄로 분리 표시

### 10.4 명세서에 포함되는 항목
- 사업자명·사업장명
- 직원명·시급·정산기간
- 일자별: 출근/퇴근 시각, 분, 야간 라벨, 환산금액
- 휴가: 일자, 유형, 환산금액
- 합계: 총 근무시간, 기본급, 주휴수당, 휴가 수당, 3.3% 공제, 실수령액

#### 주휴수당 포함 모드 직원 (4.4)
- 시급 라벨이 **`13,000원 (주휴 포함 — 근로분 10,833원 + 주휴분 2,167원/시간)`** 형태로 분해 표기

### Q. 사업장 등록은 무료인가요?
A. 베타 기간 무료. 정식 출시 후 요금 안내 예정.

### Q. 한 명만 급여 계산에서 빼고 싶어요 (수습·임원·연봉제)
A. 직원 수정 → **급여 계산 적용 OFF**. 근태는 정상 기록, 급여만 0.

### Q. 야간 근무가 1일·합계로 잡혀요
A. 자정 기준 자동 분할됩니다. 22시~06시 → 2일·각각 2시간/6시간으로 분리. PDF/CSV에도 반영.

### Q. 키오스크 모드와 개인 링크를 둘 다 쓸 수 있나요?
A. 사업장당 한 가지만. 단, 대시보드에서 언제든 전환 가능.

### Q. 명세서를 직원에게 어떻게 전달하나요?
A. **📄 PDF 출력** → 인쇄·PDF 저장·카카오톡 전송. 또는 **📊 CSV**로 메일 첨부.

### Q. 휴가 등록 버튼이 안 보여요
A. 페이지 새로고침. 그래도 안 나오면 캐시 강제 새로고침 (Mac `Cmd+Shift+R`, Windows `Ctrl+F5`).

### Q. 직원이 사업장 밖에서 출퇴근 찍으면?
A. GPS 위치 제한 설정 시 차단 ("사업장 반경 N미터 밖"). 미설정 시 어디서나 가능.

### Q. 직원이 같은 날 출퇴근을 두 번 찍을 수 있나요?
A. 가능. 점심시간으로 분리해 오전·오후 따로 근무 패턴 OK. 명세서는 합산.

### Q. 휴가 정책 OFF 토글하면 이미 등록한 휴가가 사라지나요?
A. 데이터는 보존. 화면 표시·급여 계산만 일시 제외. 다시 ON 시 즉시 복원.

### Q. 직원 삭제하면 그 직원 데이터가 영구히 사라지나요?
A. 네, 모든 근태·휴가 기록 함께 삭제. 복구 불가. 대안: **급여 계산 OFF**로 비활성화만.

### Q. 5인 미만 사업장이면 주휴수당 안 줘도 되나요?
A. 5인 미만이라도 주 15시간 이상 근무하면 주휴수당은 법정 의무. 연장·야간·휴일수당은 5인 미만 면제 대상.

### Q. 시급을 바꾸면 과거 명세서도 바뀌나요?
A. 아니요, 과거 명세서는 당시 시급으로 보존. 변경 시점 이후 근태부터 새 시급 적용.

### Q. 시급에 주휴수당을 미리 포함해서 지급할 수 있나요?
A. 가능합니다. 직원 추가/수정 페이지의 **"주휴수당을 시급에 포함" 토글 ON**으로 적용. 매뉴얼 **4.4 참고**. 시급이 자동으로 분해 표기되고(예: `13,000원 (주휴 포함 — 근로분 10,833원 + 주휴분 2,167원/시간)`), 명세서에서 별도 주휴수당 라인이 사라집니다.

## 13. 문제 해결

### 13.1 화면이 옛날 상태로 보임
- 페이지 새로고침 (`F5`)
- 강제 새로고침 (Mac `Cmd+Shift+R`, Windows `Ctrl+F5`)

### 13.2 로그인이 자꾸 풀림
- 24시간 자동 만료. 매일 한 번 PIN 재입력 정상
- 브라우저 시크릿 모드 사용 중이면 쿠키 미저장 → 일반 창 사용

### 13.3 GPS 권한이 안 됨
- 브라우저 주소창 좌측 자물쇠/카메라 아이콘 → 위치 권한 허용
- iPhone Safari: 설정 → Safari → 위치 → 허용
- Android Chrome: 설정 → 사이트 설정 → 위치 → 허용

### 13.4 출근 링크가 동작 안 함
- 직원에게 **🔄 재발급** 후 새 링크 전송
- 링크 끝 영문/숫자 8자리가 깨지지 않았는지 확인 (메신저 전송 시 자동 줄바꿈 주의)

### 13.5 명세서 PDF가 이상하게 출력됨
- 인쇄 옵션에서 **여백 0** + **배경 그래픽 인쇄** 체크
- 미리보기에서 깨지면 한 번 더 새로고침

### 13.6 "사업장이 정지되었습니다" 메시지
- 운영자에게 문의. 결제 미납이나 정책 위반 등의 사유. 정상화 후 즉시 복구.
